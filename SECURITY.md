# Security Policy

## Supported Versions

Security fixes are applied to the latest `main` branch and the most recent released version (if any). If you are running an older revision, please upgrade.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report security issues privately:

- Email: **security@your-company.example** (replace with your real address)
- Or: create a **private** GitHub Security Advisory (preferred if enabled for this repo)

Include as much of the following as possible:

- A description of the vulnerability and potential impact
- Steps to reproduce (proof-of-concept)
- Affected endpoints/components and versions/commit SHA
- Any suggested remediation

## What to Expect

- We will acknowledge receipt within **3 business days**.
- We will investigate and work on a fix as quickly as possible.
- We may request additional information to reproduce/validate the issue.

## Disclosure

We follow coordinated disclosure. Please allow a reasonable time to remediate before public disclosure.
